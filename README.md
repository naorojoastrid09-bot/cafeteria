# Cafetería

## Nombre del proyecto
Cafetería – Aplicación Web de Pedidos

## Descripción
Aplicación web responsive que permite a los clientes de la cafetería consultar el menú, visualizar precios, registrarse, seleccionar productos, crear pedidos y consultar el estado de sus pedidos desde cualquier dispositivo móvil o computadora.

## Problema que resuelve
La cafetería actualmente no cuenta con un sistema digital para que los clientes puedan consultar el menú y realizar pedidos de forma remota. Esto genera:
- Pérdida de tiempo en filas
- Dificultad para conocer precios y disponibilidad en tiempo real
- Limitaciones para atender a más clientes simultáneamente
- Falta de registro y seguimiento de pedidos

La aplicación soluciona estos problemas ofreciendo una plataforma accesible, rápida y fácil de usar.

## Funcionalidades principales
- **Consulta del menú**: Visualización completa de productos categorizados
- **Visualización de precios**: Precios actualizados de cada producto
- **Registro de clientes**: Creación de cuenta de usuario
- **Selección de productos**: Agregar productos al carrito de compras
- **Creación de pedidos**: Confirmación y envío del pedido
- **Consulta del estado del pedido**: Seguimiento en tiempo real (recibido, en preparación, listo, entregado)
